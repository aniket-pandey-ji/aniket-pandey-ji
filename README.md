## `02` About Me

I am a third-semester **Bachelor of Computer Applications (BCA)** student at **MPPG College, Jungle Dhusan, Gorakhpur**, focused on backend engineering, relational and document database systems, and practical software development.

My work centers on designing clean REST APIs, structuring database schemas, implementing authentication workflows, and shipping browser-accessible applications. Rather than chasing buzzwords, I focus on understanding how data moves from client interfaces through server-side logic into persistent storage—building and iterating on real projects from my Linux/Termux and VS Code environment.

> **Engineering Philosophy:** Learning, building, solving, and shipping real projects—preparing for backend, database engineering, and software development roles at product-based technology companies.
